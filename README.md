# Thinkfulbnb

Thinkfulbnb is a responsive web page developed as part of the Thinkful Software Engineering program. The project focuses on mobile-first development using HTML5, CSS, Flexbox, responsive images, and media queries.

**[View the Live Application](https://sprout90.github.io/Thinkful-bnb/)**

## Project Overview

The objective was to translate supplied mobile and desktop design mockups into a responsive web page that adapts to different screen sizes.

The implementation demonstrates:

* Mobile-first responsive design
* HTML5 page structure and form elements
* Flexbox-based layouts
* Responsive images
* Relative sizing and flexible content areas
* Single-page anchor navigation
* CSS media queries for mobile and desktop layouts
* Reorganization of page content based on viewport width

## Thinkful Project Context

Thinkful provided the design mockups, images, starter HTML and CSS, and project requirements.

My work focused on completing the HTML structure and CSS necessary to reproduce the supplied designs. This included implementing the responsive navigation, search form, content layouts, image behavior, Flexbox rules, and desktop media-query transformations.

The original assignment instructions are retained separately in `README.instruct.md`.
